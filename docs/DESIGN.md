# DESIGN.md

## Visual Direction

Restrained retro with modern polish. Dark arcade UI with space / observatory influence. Abstract pixel sci-fi panels, subtle parallax depth, and a central floating character display chamber.

## Layout

### Start Screen

* Title/logo
* Press Start CTA
* Persistent bottom links

### Main Screen

* Left: character roster grid
* Center: selected floating showcase character
* Right: content panel
* Bottom: LinkedIn / GitHub / CV / mute toggle

## Motion

* Smooth center transition on select.
* Gentle floating idle animation.
* Optional blink / idle frame swaps.
* Panel transitions slide/fade.
* Hover feedback on selectable elements.
* Subtle ambient particles/stars optional.

## Character Select UI Inspiration

* Fighting game roster grid.
* Mario Kart style portrait selection.
* Sci-fi selection chamber.
* Clean borders, restrained highlights.

## Color Guidance

* Deep navy / charcoal base.
* Electric cyan accents.
* Soft purple secondary accents.
* Warm highlight used sparingly.

## Typography

* Pixel display font for headings.
* Clean readable sans-serif for body text.

## Audio

* Placeholder chiptune loop.
* Character-specific variation possible later.
* UI SFX: select, panel switch.

## Mobile Behaviour

* Grid collapses to compact carousel.
* Character center scales down.
* Right panel becomes stacked below character.
